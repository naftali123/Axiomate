# UI mock-up (example data)

`mockup.html.txt` is a self-contained, backend-free mock-up of the web UI. All
company data in it is invented. To view it, copy it to a file named `mockup.html`
outside the repository (the repository allows exactly one tracked `.html` page,
`status.html`, so the mock-up is stored with a `.txt` suffix) and open it in a browser.
